# Recorder panel

Import [panel.json](https://georgefejer91.github.io/spatial-study-6-webxr/panel.json)
using Remote LSL Recorder's **+ → Import app panel**. The desktop definition
is remembered and appears automatically on an approved recorder phone session.
Use the recorder's **Share panel** for a base-page link and locally generated QR.

The stable `operator.html` entry uses the existing operator UI and BRSP target
contract. It supports the recorder's opaque iframe, stays offline on preload,
and begins public discovery only after **Connect**. SDK 1.5.5's cache hooks
are disabled when origin storage is denied; session and signaling options stay
intact. The ordinary top-level companion retains its existing public policy.

This remains the existing participant-ineligible, public-control prototype:
recorder approval does not introduce Study 6 operator identity or access control.
The experiment and APK retain their own reducer, gates, records and timing.
Only one experiment controller is admitted; connect on PC or phone deliberately.
Spectator media cannot be enabled inside this data-only panel.

Follow [Remote Panel/1](https://github.com/GeorgeFejer91/Remote-LSL-Recorder/blob/main/docs/remote-panel-profile.md)
for descriptor bounds, deployment, isolation and integration qualification.
An import or viewport test does not qualify physical Quest/phone, route selection
or scientific timing.
