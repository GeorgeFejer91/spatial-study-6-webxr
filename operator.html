    Privacy and network disclosure

    Discovery and control contact VDO.Ninja’s public signaling and STUN/TURN infrastructure. A direct WebRTC route can disclose peer IP addresses. If optional monitoring was explicitly enabled, its spectator image may contain participant-entered text. The public beacon is not identity authentication: any browser visiting this page can derive the same session key and request the existing bounded Study 6 operator scopes. The target still accepts only typed experiment commands and never sends raw ECG, participant identifiers, demographics, or questionnaire answers. A manually supplied private descriptor may be retained locally until Forget pairing; URL fragments are removed before any connection starts.

    Setup and participant allocation

    The participant code is sent only as a bounded acknowledged command and is never returned in companion status. Names, demographics, consent, and questionnaire answers must still be entered locally in the headset.

    Commands use BRSP mutual proof, negotiated scopes, revision fencing, and applied acknowledgements. They are rejected unless the experiment’s reducer allows them. WebXR owns questionnaire and condition control; sensor export and recording finalization are bounded requests to the APK recorder. Records never traverse this channel. The companion can select the pseudonymous participant code, but cannot enter names or demographics, answer questionnaires, grant consent, start immersive VR, or erase local data.
